# Restaurant RAG

RAG-система для рекомендации ресторанов: отвечает на вопросы о заведении, опираясь на отзывы из датасета, а не только на знания модели.

Пользователь задаёт вопрос в терминале → система находит релевантные отзывы → LLM формирует ответ на их основе.

## Стек

| Компонент | Технология |
|-----------|------------|
| Оркестрация | LangChain |
| LLM | Ollama (`llama3.2`) |
| Эмбеддинги | Ollama (`mxbai-embed-large`) |
| Векторное хранилище | Chroma |
| Данные | Pandas + CSV с отзывами |
| Мониторинг | LangFuse |

Также используются `python-dotenv` для конфигурации и CallbackHandler LangFuse для трейсинга промптов и ответов модели.

## Как это работает

1. `vector.py` загружает отзывы из `realistic_restaurant_reviews.csv`, строит эмбеддинги и сохраняет их в Chroma.
2. `main.py` принимает вопрос, достаёт top-k релевантных отзывов через retriever и передаёт их в промпт вместе с вопросом.
3. Ollama генерирует ответ; LangFuse фиксирует вызовы для мониторинга и отладки.

## Запуск

1. Скопируйте `.env.example` в `.env` и заполните ключи (Ollama host, LangFuse).
2. Установите зависимости:

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

3. Убедитесь, что Ollama запущена и доступны модели `llama3.2` и `mxbai-embed-large`.
4. Запустите приложение:

```bash
python main.py
```

Введите вопрос или `q`, чтобы выйти.
